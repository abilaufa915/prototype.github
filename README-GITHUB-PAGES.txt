DEADLINEGUARD — GITHUB PAGES

UPLOAD FILES TO THE ROOT OF THE REPOSITORY (main branch):
- index.html
- manifest.json
- sw.js
- icons/ (folder and its PNG files)

IMPORTANT:
1. Upload the CONTENTS of this package, not the enclosing folder.
2. Keep index.html directly in the repository root.
3. Keep README.md if you like; it is no longer the site homepage once index.html exists.
4. GitHub repository Settings > Pages should publish branch main and folder /(root).
5. Then open https://abilaufa915.github.io/prototype.github/ and refresh.

This package contains the static PWA frontend. Web Push while the app is closed still needs a separately hosted, configured push backend; GitHub Pages itself is static hosting.
